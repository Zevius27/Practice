Set Theory Fundamentals

What is a Set?

A set is a well-defined collection of distinct objects. These objects are called elements or members. Sets are fundamental building blocks in mathematics.

A = {1, 2, 3, 4, 5} — A set of numbers B = {red, blue, green} — A set of colors C = {x | x is an even number less than 10} — Set-builder notation
Notation matters! Use ∈ for "element of" (3 ∈ A) and ∉ for "not an element" (7 ∉ A)

Venn Diagrams

Visual representations showing relationships between sets using overlapping circles. Perfect for understanding unions, intersections, and complements at a glance.

Subsets

A set A is a subset of B (written A ⊆ B) if every element of A is also in B.

  • Proper subset: A ⊂ B means A ⊆ B and A ≠ B
  • Empty set: ∅ is a subset of every set
  • Every set is a subset of itself
Don't confuse ∈ (element of) with ⊆ (subset of)! {3} ⊆ {1,2,3} but 3 ∈ {1,2,3}

Cardinality (Size of a Set)

The cardinality |A| is the number of elements in set A.

  • |{1, 2, 3}| = 3
  • |∅| = 0
  • Finite sets have countable cardinality
  • Infinite sets (ℕ, ℝ) have infinite cardinality

Power Set

The power set P(A) or 2^A is the set of all subsets of A.

If |A| = n, then |P(A)| = 2^n
If A = {1, 2}, then P(A) = {∅, {1}, {2}, {1,2}} Here |A| = 2, so |P(A)| = 2² = 4 ✓
Power sets grow exponentially! A set with 5 elements has 32 subsets.

Cartesian Products

The Cartesian product A × B is the set of all ordered pairs (a, b) where a ∈ A and b ∈ B.

A × B = {(a, b) | a ∈ A and b ∈ B}
A = {1, 2}, B = {x, y} A × B = {(1,x), (1,y), (2,x), (2,y)} |A × B| = |A| × |B| = 2 × 2 = 4
Order matters! A × B ≠ B × A in general. (1,x) ≠ (x,1)

Set Operations

Union (A ∪ B)

All elements in A or B or both.

A ∪ B = {x | x ∈ A or x ∈ B}

Intersection (A ∩ B)

Elements common to both A and B.

A ∩ B = {x | x ∈ A and x ∈ B}

Difference (A − B)

Elements in A but not in B.

A − B = {x | x ∈ A and x ∉ B}

Complement (A' or Ā)

All elements in the universal set U that are not in A.

A' = U − A = {x | x ∈ U and x ∉ A}
U = {1,2,3,4,5,6}, A = {1,2,3}, B = {3,4,5} A ∪ B = {1,2,3,4,5} A ∩ B = {3} A − B = {1,2} A' = {4,5,6}

Disjoint Sets

Two sets are disjoint if A ∩ B = ∅ (no common elements).

Draw Venn diagrams for complex operations! They prevent careless mistakes.

Set Identities (Must Know!)

These are your proof weapons. Memorize them!

Fundamental Laws

  • Identity Laws: A ∪ ∅ = A, A ∩ U = A
  • Domination Laws: A ∪ U = U, A ∩ ∅ = ∅
  • Idempotent Laws: A ∪ A = A, A ∩ A = A
  • Complement Laws: A ∪ A' = U, A ∩ A' = ∅
  • Double Complement: (A')' = A

Commutative & Associative

  • Commutative: A ∪ B = B ∪ A, A ∩ B = B ∩ A
  • Associative: (A ∪ B) ∪ C = A ∪ (B ∪ C)
  • Same for intersection

Distributive Laws

A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C) A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
Think of ∪ like addition and ∩ like multiplication. Distributive laws work similarly!

De Morgan's Laws ⭐ CRITICAL

(A ∪ B)' = A' ∩ B' (A ∩ B)' = A' ∪ B'
Students often flip these wrong! "Complement flips union to intersection and vice versa"

Absorption Laws

  • A ∪ (A ∩ B) = A
  • A ∩ (A ∪ B) = A

Generalized Unions & Intersections

When dealing with a collection of sets A₁, A₂, A₃, ..., Aₙ:

⋃ᵢ₌₁ⁿ Aᵢ = A₁ ∪ A₂ ∪ ... ∪ Aₙ (all elements in at least one set) ⋂ᵢ₌₁ⁿ Aᵢ = A₁ ∩ A₂ ∩ ... ∩ Aₙ (elements in all sets)
A₁ = {1,2}, A₂ = {2,3}, A₃ = {2,4} ⋃ Aᵢ = {1,2,3,4} ⋂ Aᵢ = {2}

Cardinality of Unions

|A ∪ B| = |A| + |B| − |A ∩ B|

For three sets:

|A ∪ B ∪ C| = |A| + |B| + |C| − |A ∩ B| − |A ∩ C| − |B ∩ C| + |A ∩ B ∩ C|
This is inclusion-exclusion principle. Add individual sets, subtract pairwise overlaps, add back triple overlap!

Functions

Definition

A function f from set A to set B (written f: A → B) assigns exactly one element of B to each element of A.

  • Domain: Set A (input values)
  • Codomain: Set B (possible output values)
  • Range: Actual outputs {f(a) | a ∈ A} ⊆ B
Range ≠ Codomain! Range is subset of codomain containing only actual outputs.
f: {1,2,3} → {a,b,c,d} where f(1)=a, f(2)=a, f(3)=c Domain = {1,2,3} Codomain = {a,b,c,d} Range = {a,c}

Types of Functions

1. Injective (One-to-One) 💉

Different inputs produce different outputs.

f is injective if f(x₁) = f(x₂) implies x₁ = x₂

Equivalently: if x₁ ≠ x₂, then f(x₁) ≠ f(x₂)

f(x) = 2x is injective (no two numbers give same double) f(x) = x² is NOT injective (f(-2) = f(2) = 4)
Horizontal line test! If any horizontal line crosses graph twice, not injective.

2. Surjective (Onto) 📤

Every element in codomain is an output (range = codomain).

f is surjective if for every b ∈ B, there exists a ∈ A such that f(a) = b
f: ℝ → ℝ, f(x) = 2x is surjective (every real number is double of something) f: ℝ → ℝ, f(x) = x² is NOT surjective (negative numbers never appear)

3. Bijective (One-to-One Correspondence) ✨

Both injective AND surjective. Perfect pairing between domain and codomain!

  • Every element in codomain used exactly once
  • Bijections are invertible
  • |A| = |B| if bijection exists
To prove bijection: show it's both injective (different inputs → different outputs) and surjective (all codomain covered)

Inverse Functions

If f: A → B is bijective, then inverse function f⁻¹: B → A exists.

f⁻¹(b) = a if and only if f(a) = b f⁻¹(f(a)) = a and f(f⁻¹(b)) = b
Only bijective functions have inverses! Check both injective and surjective first.
f(x) = 3x + 2 is bijective on ℝ To find inverse: y = 3x + 2 → x = (y-2)/3 Therefore f⁻¹(x) = (x-2)/3 Check: f⁻¹(f(5)) = f⁻¹(17) = 15/3 = 5 ✓

Composition of Functions

Combining functions: (g ∘ f)(x) = g(f(x))

Read right to left: "g composed with f" means apply f first, then g.

If f: A → B and g: B → C, then g ∘ f: A → C
f(x) = x + 1, g(x) = 2x (g ∘ f)(x) = g(f(x)) = g(x+1) = 2(x+1) = 2x + 2 (f ∘ g)(x) = f(g(x)) = f(2x) = 2x + 1 Note: g ∘ f ≠ f ∘ g in general!

Properties of Composition

  • Associative: (h ∘ g) ∘ f = h ∘ (g ∘ f)
  • Not commutative: g ∘ f ≠ f ∘ g usually
  • If f and g are injective, g ∘ f is injective
  • If f and g are surjective, g ∘ f is surjective
  • If f and g are bijective, g ∘ f is bijective
For inverses of compositions: (g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹ (reverse order!)

Identity Function

The identity function Iₐ: A → A is defined by Iₐ(x) = x for all x ∈ A.

  • f ∘ Iₐ = f
  • Iв ∘ f = f
  • f ∘ f⁻¹ = Iв and f⁻¹ ∘ f = Iₐ

Relations

Binary Relations

A binary relation R from A to B is a subset of A × B.

If (a,b) ∈ R, we write aRb (a is related to b).

A = {1,2,3}, B = {x,y} R = {(1,x), (2,x), (2,y)} is a relation from A to B We can say: 1Rx, 2Rx, 2Ry

Relations on a Set

A relation on set A is a subset of A × A (relates elements to themselves).

Properties of Relations

1. Reflexive

Every element is related to itself.

∀a ∈ A: (a,a) ∈ R
"≤" on integers is reflexive (a ≤ a always)

2. Symmetric

If aRb, then bRa.

∀a,b ∈ A: (a,b) ∈ R → (b,a) ∈ R
"is sibling of" is symmetric

3. Antisymmetric

If aRb and bRa, then a = b.

∀a,b ∈ A: [(a,b) ∈ R and (b,a) ∈ R] → a = b
"≤" is antisymmetric (if a ≤ b and b ≤ a, then a = b)
Antisymmetric ≠ "not symmetric"! A relation can be both, neither, or one but not the other.

4. Transitive

If aRb and bRc, then aRc.

∀a,b,c ∈ A: [(a,b) ∈ R and (b,c) ∈ R] → (a,c) ∈ R
"<" is transitive (if a < b and b < c, then a < c)
Check all four properties systematically! Missing one changes everything.

n-ary Relations

An n-ary relation on sets A₁, A₂, ..., Aₙ is a subset of A₁ × A₂ × ... × Aₙ.

  • Binary relation: n = 2
  • Ternary relation: n = 3
  • Useful in databases (tables are n-ary relations!)
Student database relation R ⊆ Names × IDs × Grades ("Alice", 101, "A"), ("Bob", 102, "B+") ∈ R

Representing Relations

1. Matrix Representation

For relation R on finite sets, create matrix M where Mᵢⱼ = 1 if (aᵢ,aⱼ) ∈ R, else 0.

A = {1,2,3}, R = {(1,1), (1,2), (2,3), (3,1)} 1 2 3 1 [ 1 1 0 ] 2 [ 0 0 1 ] 3 [ 1 0 0 ]
Reflexive → diagonal all 1s. Symmetric → matrix equals its transpose!

2. Directed Graph (Digraph)

Vertices represent elements, directed edges represent ordered pairs in R.

  • Vertex for each element of A
  • Arrow from a to b if (a,b) ∈ R
  • Loop at vertex a if (a,a) ∈ R
Reflexive → loop at every vertex. Symmetric → arrows go both ways. Transitive → if path exists, direct arrow exists.

Closures of Relations

The closure of R with respect to property P is the smallest relation containing R that has property P.

Reflexive Closure

Add all pairs (a,a) for a ∈ A.

r(R) = R ∪ {(a,a) | a ∈ A}

Symmetric Closure

Add (b,a) whenever (a,b) ∈ R.

s(R) = R ∪ {(b,a) | (a,b) ∈ R}

Transitive Closure

Add (a,c) whenever path from a to c exists.

Computed using Warshall's Algorithm or by R ∪ R² ∪ R³ ∪ ...

R = {(1,2), (2,3)} Transitive closure: t(R) = {(1,2), (2,3), (1,3)} (Added (1,3) because of path 1→2→3)
For transitive closure on n elements, need at most R ∪ R² ∪ ... ∪ Rⁿ

Equivalence Relations ⭐

A relation R on A is an equivalence relation if it is:

  • Reflexive: aRa for all a
  • Symmetric: aRb implies bRa
  • Transitive: aRb and bRc implies aRc
"has same birthday as" is equivalence relation ✓ Reflexive: you have same birthday as yourself ✓ Symmetric: if you share birthday with Bob, Bob shares with you ✓ Transitive: if A and B share, B and C share, then A and C share
Congruence modulo n: a ≡ b (mod n) if n divides (a-b) This is an equivalence relation! Example: 7 ≡ 12 (mod 5) because 5 divides (12-7)

Equivalence Classes

The equivalence class of element a is:

[a] = {b ∈ A | aRb}

All elements related to a.

For ≡ (mod 3) on ℤ: [0] = {..., -6, -3, 0, 3, 6, 9, ...} (multiples of 3) [1] = {..., -5, -2, 1, 4, 7, 10, ...} (one more than multiple of 3) [2] = {..., -4, -1, 2, 5, 8, 11, ...} (two more than multiple of 3)

Properties of Equivalence Classes

  • Every element belongs to exactly one equivalence class
  • Either [a] = [b] or [a] ∩ [b] = ∅
  • Union of all equivalence classes = A
  • Equivalence classes are disjoint
If aRb, then [a] = [b]. If a not related to b, classes are completely separate!

Partitions

A partition of set A is a collection of nonempty, disjoint subsets whose union is A.

A₁, A₂, ..., Aₙ partition A if: • Aᵢ ≠ ∅ for all i • Aᵢ ∩ Aⱼ = ∅ for i ≠ j • A₁ ∪ A₂ ∪ ... ∪ Aₙ = A

Key Theorem

⚡ Equivalence classes of an equivalence relation form a partition of the set!
⚡ Every partition defines an equivalence relation!
A = {1,2,3,4,5,6} Partition: {{1,4}, {2,5}, {3,6}} Defines relation: 1R4, 4R1, 2R5, 5R2, 3R6, 6R3, plus reflexive pairs
Don't forget reflexive pairs when converting partition to relation!

Partial Ordering (Poset)

A relation R on set A is a partial order if it is:

  • Reflexive: aRa for all a
  • Antisymmetric: aRb and bRa implies a = b
  • Transitive: aRb and bRc implies aRc

The set A with partial order R is called a poset (A, R).

(ℕ, ≤) is a poset ✓ Reflexive: n ≤ n ✓ Antisymmetric: if a ≤ b and b ≤ a, then a = b ✓ Transitive: if a ≤ b and b ≤ c, then a ≤ c
(P(S), ⊆) — power set with subset relation is a poset For S = {1,2}: ({}, {{1}, {2}, {1,2}}, ⊆)

Comparable vs Incomparable

Elements a and b are comparable if aRb or bRa.

Elements are incomparable if neither aRb nor bRa.

In (P({1,2}), ⊆): {1} and {1,2} are comparable: {1} ⊆ {1,2} {1} and {2} are incomparable: neither is subset of other

Total Order (Linear Order)

A partial order where every pair is comparable.

(ℕ, ≤) is total order. (P(S), ⊆) is NOT total order (incomparable elements exist)

Special Elements in Posets

Maximal element: No element greater than it

Minimal element: No element less than it

Greatest element (maximum): Greater than or equal to all elements

Least element (minimum): Less than or equal to all elements

Maximal ≠ maximum! Poset can have multiple maximal elements but at most one maximum.
Consider divisibility on {2, 3, 4, 6}: Minimal elements: 2, 3 (no smaller divisors in set) No minimum (2 and 3 are incomparable) Maximal elements: 4, 6 (nothing in set divides them except themselves) No maximum (4 and 6 are incomparable)

Upper bound: Element ≥ all elements in subset

Lower bound: Element ≤ all elements in subset

Least upper bound (supremum/lub): Smallest upper bound

Greatest lower bound (infimum/glb): Largest lower bound

Hasse Diagrams

A Hasse diagram is a visual representation of a finite poset, showing ordering relationships without redundancy.

Construction Rules

  • Draw each element as a vertex
  • Place larger elements higher than smaller
  • Draw edge from a to b if a < b and no element between them
  • Remove: reflexive loops, transitive redundancies, arrow directions (implied upward)
Think "family tree" — draw only direct parent-child relationships, not grandparents!
Poset ({1,2,3,6}, divides): Hasse diagram structure: 6 / \ 2 3 \ / 1 (1 divides everything, 6 is divided by everything in set)
Power set P({a,b}) with ⊆: {a,b} / \ {a} {b} \ / ∅ Perfectly symmetric!

Reading Hasse Diagrams

  • Path upward: means less than or equal to (≤)
  • Maximal elements: top vertices (no vertex above)
  • Minimal elements: bottom vertices (no vertex below)
  • Maximum: single top vertex connected to all below (if exists)
  • Minimum: single bottom vertex connected to all above (if exists)
To check if a ≤ b: trace upward path from a to b. If path exists, a ≤ b!

Chains and Antichains

Chain: Subset where all elements are comparable (forms vertical line in Hasse)

Antichain: Subset where no two elements are comparable (forms horizontal level)

In divisibility poset {1,2,3,6}: Chain: {1, 2, 6} (1|2|6) Antichain: {2, 3} (neither divides other)
Maximum chain length = height of Hasse diagram. Maximum antichain = width of widest level.

Topological Sort

A topological sort is a linear ordering of vertices in a directed acyclic graph (DAG) such that for every edge (u,v), u comes before v.

When Does It Exist?

Topological sort exists if and only if the graph is a DAG (no cycles).

If graph has cycle, no topological sort possible! Check for cycles first.

Algorithm (Kahn's Method)

  • Find a vertex with no incoming edges (in-degree = 0)
  • Add it to the sorted list
  • Remove that vertex and its outgoing edges
  • Repeat until all vertices processed
Tasks with dependencies: A → B (A before B) A → C B → D C → D Step-by-step: 1. A has in-degree 0 → output A, remove A 2. B and C now have in-degree 0 → output B (or C) 3. Output C (or B) 4. D now has in-degree 0 → output D Valid sorts: A,B,C,D or A,C,B,D
Multiple valid topological sorts usually exist! Any order respecting dependencies is valid.

DFS-Based Method

  • Perform DFS on graph
  • When backtracking from vertex, add to front of list
  • Vertices with later finish times come first in sort

Applications

  • Course prerequisites: order to take classes
  • Build systems: compilation order
  • Task scheduling: order tasks with dependencies
  • Makefile execution: determine build order
Course prerequisites: Math101 → Math201 → Math301 Math101 → CS101 → CS201 Possible topological order: Math101, CS101, Math201, CS201, Math301 (Many others valid too!)
In exams: if asked to find "a" topological sort, find any valid one. If asked for "all", list all possibilities respecting dependencies.

Relation to Partial Orders

Topological sort converts a partial order into a total order (linear sequence) compatible with the partial order.

⚡ From Hasse diagram to topological sort: start from bottom (minimal elements), work upward, respecting all edges!

🎯 Quick Revision Summary

Set Theory Essentials

  • Power set: |P(A)| = 2^|A|
  • Cartesian product: |A × B| = |A| × |B|
  • De Morgan's: (A ∪ B)' = A' ∩ B', (A ∩ B)' = A' ∪ B'
  • Inclusion-exclusion: |A ∪ B| = |A| + |B| − |A ∩ B|

Function Types Recognition

  • Injective: Different inputs → different outputs (one-to-one)
  • Surjective: All codomain covered (onto)
  • Bijective: Both injective and surjective (invertible!)

Relation Properties Checklist

  • Reflexive: (a,a) for all a
  • Symmetric: (a,b) → (b,a)
  • Antisymmetric: (a,b) and (b,a) → a=b
  • Transitive: (a,b) and (b,c) → (a,c)

Key Combinations

  • Equivalence: Reflexive + Symmetric + Transitive
  • Partial Order: Reflexive + Antisymmetric + Transitive
  • Total Order: Partial order + all pairs comparable

Visual Tools

  • Venn diagrams: Set operations
  • Matrices: Relation properties
  • Digraphs: Relation structure
  • Hasse diagrams: Partial orders (remove redundancy)
⚡ Exam Strategy:
1. For sets: draw Venn diagrams
2. For functions: check injective & surjective separately
3. For relations: verify all 4 properties systematically
4. For posets: draw Hasse diagram first
5. For topological sort: check for cycles, then start with in-degree 0
Common Mistakes to Avoid:
✗ Confusing ∈ with ⊆
✗ Thinking antisymmetric = not symmetric
✗ Forgetting range ≠ codomain
✗ Mixing up composition order (g ∘ f means f first!)
✗ Claiming maximal = maximum
